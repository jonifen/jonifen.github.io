MacBook Air 2015

1 Jan, 0001 · by · Reading time: ~1 minutes (129 words)

This is my “beater” laptop, meaning that it’s the machine that I can take anywhere and not be too fussed if it takes a knock or two along the way. I bought it on eBay a few months back in a really good deal, as the usual Lenovos are quite expensive nowadays for what they are.

Specifications

  • MacBookAir7,2
  • 4 × Intel® Core™ i7-5650U CPU @ 2.20GHz
  • 8GB RAM
  • Intel HD Graphics 6000
  • 1TB NVMe SSD

Installed

I have a dual boot setup, so I can retain macOS just in case there’s any firmware updates etc. but generally I’m not expecting much on that front given its age. However, I mostly use the Linux install for everything else.

  • MacOS Monterey
  • Arch Linux
  • KDE Plasma
  • Firefox
  • Visual Studio Code
  • Alacritty
  • Neovim
